# DineFlow Backend

Express API for the DineFlow restaurant management prototype.

## Run

```bash
npm install
npm run dev
```

The API starts on `http://localhost:4000`.

## Endpoints

- `GET /api/health`
- `GET /api/app`
- `GET /api/overview`
- `GET /api/menu`
- `POST /api/menu`
- `PATCH /api/menu/:id`
- `GET /api/operations`
- `GET /api/kitchen`
- `GET /api/analytics`
- `GET /api/staff`
- `GET /api/billing`
- `GET /api/reservations`
- `GET /api/public-menu`
- `GET /api/orders`
- `POST /api/orders`
